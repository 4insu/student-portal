# Student Portal
## Overview
A student portal web app for managing courses, grades, and profiles.
## Prerequisites
- Node.js >= 18
- npm >= 9
## Installation
```bash
git clone https://github.com/4insu/student-portal.git
cd student-portal
npm install
```
## Running the App
```bash
npm start
```
The app runs on https://localhost:3000 by default.
## Project Structure
= /src - application source code
- /tests - unit and integration tests
- /docs - additional documentation
